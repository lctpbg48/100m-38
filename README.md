## 先把“大带宽”这三个字拆开

带宽和流量是两个东西，很多第一次租服务器的人会在这里栽跟头。

- **Mbps 是端口速率**，决定同一时刻最多能流多少数据。100Mbps 约等于 12.5MB/s 的峰值。
- **流量是月度额度**，决定你这一个月总共能搬多少数据出去。
- **上行和下行经常不对称**。宣传页上写“100M”，要看清楚是上行 100M 还是“上行 25M、下行 100M”。做下载分发、视频回源、备份上传的业务，看得是上行那一个数。

还有一个容易被忽略的点：**独享还是共享**。雨云部分游戏云机型是 NAT 模式，多人共用一个公网 IP，靠端口映射开放 15 个端口；要独享公网 IP 得单独加钱，香港、日本、韩国这些区域一般是 5 元/个/月，韩国还有原生 IP（10 元/个/月）和住宅 IP（25 元/个/月）可选，日本可以加 30 元/月上一个 300G 高防 IP。

至于线路，BGP、CN2、软银、AS9929 这些名词不改变标称带宽，改的是延迟和丢包。国内业务选 BGP 或电信单线，跨境业务再去看 CN2 和软银。

## 按场景往回推，比按参数挑更省事

**视频、软件下载、镜像分发**：优先看独享端口和不限流量，广州番禺 200M 不限流量是最省心的选择；预算有限就选限流量型 + 备好流量包预算，日本和德国的流量包单价都不高。

**直播推流**：上行带宽是命门。这里要特别注意不限流量型上行只有 15～25M 的设定，推流码率一旦上去就会顶到天花板。国内推流选广州或温州的高防机型，跨境推流看韩国和日本。

**跨境独立站、外贸**：香港四区和韩国首尔兼顾国内访问速度，香港走软银混合线路，韩国走三网直连。IP 类型上，韩国支持原生和住宅 IP，做特定平台的业务会需要。

**对攻击敏感的站**：温州、绍兴、宁波、镇江这几个节点 100G～200G 防御是标配或低价可加，比事后被打爆再迁移划算得多。

## 几个容易踩的坑

**只看带宽数字，不看上行。** “100M”背后可能是上行 25M 加下行 100M，也可能是上下行都 100M。下载型业务对下行敏感，上传、推流、备份对上行敏感，别搞反。

**把叠加流量当成永久免费流量。** 叠加是顺延到下个月，不是无限累积。而且超量后限速到 5Mbps（韩国首尔是 1Mbps），这个速度基本只能维持基础连接。流量包要提前备好预算。

**NAT 机型和独立 IP 混为一谈。** NAT 机型共用公网 IP，端口映射默认开放 15 个，做需要固定 IP 或 80/443 直连的业务会受限。加独立 IP 是另一个价钱。

**忘记算防御的费用。** 部分区域的防御是标配，部分是可选加购（比如日本 300G 高防 IP 是 30 元/月）。攻击来了再临时加，往往来不及。
